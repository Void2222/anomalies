# Anomalies Mod

Мод добавляет гибкую систему аномалий, полностью управляемую через JSON-датапаки и NBT-теги. Каждая аномалия представляет собой пространственную область с собственными слоями воздействия, физикой, визуальными эффектами и уроном.

---

## 🛠 Основные возможности

* **JSON-шаблоны и NBT-оверрайды:** Базовые конфигурации аномалий загружаются из датапаков (`data/<mod_id>/anomalies/*.json`), но параметры любой отдельной сущности в мире (радиусы, урон, частицы) можно переопределять прямо в игре через NBT-тег `customOverrides`.
* **Многослойная физика и зоны:** Каждая аномалия может содержать несколько слоев воздействия с настраиваемыми радиусами, силой притяжения к центру, тангенциальным вращением, импульсами по оси Y и наложением горения.
* **Оптимизация (LOD):**
* **Сервер:** Триггерный сканер переходит в спящий режим, если в радиусе 48 блоков нет игроков.
* **Клиент:** Генерация частиц и просчет визуализаций отсекаются на расстоянии свыше 70 блоков.
* **API для разработчиков:** Набор отменяемых событий Forge для интеграции собственной игровой логики и реакций.

---

## 🔧 Мультитул Администратора

Инструмент `AnomalyMultitoolItem` предназначен для настройки и управления аномалиями в мире. Режимы переключаются комбинацией **Shift + ПКМ по воздуху**:

* **ANALYZE (Анализ)**
    * **Управление:** ПКМ по аномалии
    * **Назначение:** Выводит в чат характеристики аномалии (размеры, зоны, физику, урон) и подсвечивает локальные NBT-оверрайды `[Override]`.
* **MODIFY (Изменение)**
    * **Управление:** ПКМ — сессия / Shift+ПКМ — сброс
    * **Назначение:** Запускает пошаговое изменение параметров через чат или полностью сбрасывает оверрайды до значений из JSON.
* **RELOCATE (Перемещение)**
    * **Управление:** ПКМ — захват / ЛКМ по блоку / Shift+ПКМ
    * **Назначение:** Переносит аномалию на выбранный блок или сдвигает ее по координатам через чат (`dx dy dz`).
* **DELETE (Удаление)**
    * **Управление:** ЛКМ по аномалии / Shift+ЛКМ
    * **Назначение:** Безопасное удаление с 5-секундным подтверждением от случайного клика или мгновенное удаление с зажатым Shift.

## 📜 Команды

* `/anomaly create <type>` — создает аномалию указанного типа на координатах игрока (поддерживает автокомплит зарегистрованных типов).
* `/anomaly ignore <player> <true|false>` — добавляет или удаляет игрока из списка защиты (защищенных игроков не задевают физика и урон аномалий).

---

## 💻 API для Разработчиков

Все события публикуются на `MinecraftForge.EVENT_BUS` и могут быть отменены (`@Cancelable`):

* `AnomalyTriggerEvent` — вход сущности в область действия аномалии.
* `AnomalyDamageEvent` — расчет и нанесение урона сущности.
* `AnomalyPhysicsEvent` — вычисление и применение векторов притяжения/вращения.
* `AnomalyZoneTransitionEvent` — пересечение сущностью границ между внутренними слоями зон.
* `AnomalyItemInteractEvent` — попадание выпадающих предметов (`ItemEntity`) в зону аномалии.
