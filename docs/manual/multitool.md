# 🛠️ Мультитул администратора (Anomaly Multitool)

**Мультитул аномалий** (`anomaly_multitool`) — это интерактивный инструмент для анализа, настройки, перемещения и удаления аномалий в мире в реальном времени.

---

## 🔄 Переключение режимов

Переключение режимов осуществляется комбинацией:
**`Shift + ПКМ по воздуху`**

Доступно 4 режима:
1. `ANALYZE` (Анализатор)
2. `MODIFY` (Редактор)
3. `RELOCATE` (Переместитель)
4. `DELETE` (Удалитель)

---

## 1. 🔍 Режим ANALYZE (Анализ)
*Предназначен для детального рентгена аномалии.*

- **Действие:** **ПКМ** по аномалии.
- **Результат:** В чат выводится исчерпывающая сводка:
  - Тип аномалии и UUID.
  - Текущая активная фаза.
  - Список всех доступных состояний из JSON/датапаков.
  - Геометрические размеры (хитбокс).
  - Слои зон: радиусы, урон, сила втягивания, вращение и вертикальный подброс.
  - Настройки частиц и звуков.
  - Значения, изменённые вручную через NBT-оверрайды, подсвечиваются меткой `[NBT]`.

---

## 2. ✏️ Режим MODIFY (Редактирование)
*Позволяет на лету менять параметры аномалии.*

- **Действие (ПКМ):** Открывает клиентский графический интерфейс (**GUI**).
  - Настройка ширины и высоты.
  - Радиус зоны триггера.
  - Включение/отключение втягивания в эпицентр.
  - По нажатию «Сохранить» оверрайды мгновенно применяются на сервере и синхронизируются всем игрокам вокруг.
- **Быстрый сброс (Shift + ПКМ):** Полностью очищает все ручные оверрайды и возвращает аномалию к дефолтным значениям из JSON-файлов датапака.

---

## 3. 📍 Режим RELOCATE (Перемещение)
*Позволяет быстро перенести аномалию в другую точку мира.*

- **Обычный перенос:**
  1. **ПКМ** по аномалии — аномалия выбирается для переноса.
  2. **ЛКМ** по любому блоку в мире — аномалия мгновенно перемещается на этот блок.
- **Относительный сдвиг по координатам (Shift + ПКМ):**
  1. Зажмите `Shift` и нажмите **ПКМ** по аномалии.
  2. В чате появится запрос на ввод смещения.
  3. Введите в чат 3 числа через пробел (например: `0.5 1.0 -0.5`).
  4. Аномалия плавно сдвинется на указанное расстояние.

---

## 4. 🗑️ Режим DELETE (Удаление)
*Безопасное удаление аномалии из мира и из чанка.*

- **Мгновенное удаление:** **`Shift + ЛКМ`** по аномалии.
- **Удаление с подтверждением:** Одиночный **`ЛКМ`** по аномалии выводит предупреждение в чат. Если кликнуть повторно в течение 5 секунд — аномалия будет стёрта.
