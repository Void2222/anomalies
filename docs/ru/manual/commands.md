# 💻 Командный интерфейс (Console Commands)

Все команды мода регистрируются под корневым пространством `/anomaly` и требуют уровня прав оператора (уровень 2 и выше).

---

## 1. `/anomaly create <type>`
Спавнит новую аномалию указанного типа на позиции игрока.

- **Параметры:**
  - `type` — строковый идентификатор аномалии из загруженных датапаков (`zharka`, `smart_zharka` и др.). Поддерживает автодополнение (Tab).
- **Пример:**
  ```text
  /anomaly create smart_zharka
  ```

---

## 2. `/anomaly state set <state>`
Принудительно переключает текущую фазу ближайшей аномалии (в радиусе 10 блоков от игрока).

- **Параметры:**
  - `state` — имя целевого состояния (`idle`, `warmup`, `burst`, `cooldown`). Поддерживает автодополнение только валидными состояниями найденной аномалии.
- **Пример:**
  ```text
  /anomaly state set burst
  ```

---

## 3. `/anomaly ignore <player> <true|false>`
Управляет списком игнорирования аномалий для конкретного игрока (режим Бога для создателей карт и тестеров).

- **Параметры:**
  - `player` — селектор или ник игрока.
  - `true` — включить игнорирование (аномалии перестают притягивать, наносить урон и реагировать триггерами на этого игрока).
  - `false` — выключить игнорирование.
- **Пример:**
  ```text
  /anomaly ignore Dev true
  ```
- **Хранение данных:** Список игнорируемых игроков сохраняется в JSON-файле конфигурации: `config/anomalies_ignored_players.json`. Настройки сохраняются между перезапусками сервера/мира.
