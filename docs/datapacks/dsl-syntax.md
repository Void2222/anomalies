# 📜 Спецификация языка сценариев .anom (DSL Syntax)

Файлы `.anom` описывают конечные автоматы (State Machine) аномалий: декларацию состояний, правила переходов по таймерам, шансам или событиям игрока, а также подключение рецептов трансмутации.

---

## 📁 Расположение и валидация

- **Путь:** `data/<mod_id>/anomalies/<folder_name>/<folder_name>.anom`
- Имя файла **обязано совпадать** с именем папки аномалии (например, `data/anomalies/anomalies/zharka/zharka.anom`).
- Реестр: `AnomalyScriptRegistry`, загрузчик: `AnomalyScriptLoader`.

---

## 🔤 Базовый синтаксис

### 1. Объявление начального состояния
Каждый скрипт обязан объявлять начальное состояние через ключевое слово `initial`:

```antlr
initial state idle;
```

---

### 2. Подключение внешних рецептов
Рецепты привязываются глобально в начале файла:

```antlr
recipe cook_pork --> "recipes/cook_pork.json";
recipe make_glass --> "recipes/make_glass.json";
```

---

### 3. Структура состояния (`state`)

```antlr
state <state_name> {
    // 1. Подключение активных рецептов в этой фазе (опционально)
    recipe {
        cook_pork;
        make_glass;
    }

    // 2. Правила переходов
    when <условие> -> <следующее_состояние>;
}
```

---

## 🎯 Поддерживаемые условия (`ICondition`)

Переходы задаются конструкцией `when <выражение> -> <целевое_состояние>;`:

| Условие | Синтаксис | Описание |
|---|---|---|
| **Таймер** | `timer(ticks)` | Истинно, когда аномалия непрерывно находится в данном состоянии $\ge$ `ticks` тиков (`timer(20)` = 1 сек). |
| **Вероятность** | `chance(val)` | Проверяет шанс каждый тик (`chance(0.05)` = 5% шанс в тик). |
| **Игрок в зоне** | `player.in_zone(idx)` | `true`, если игрок находится внутри зоны с индексом `idx` (0, 1, 2...). |
| **Вход игрока** | `player.entered_zone(idx)` | Срабатывает однократно в тик входа игрока в зону с индексом `idx`. |
| **Выход игрока** | `player.exited_zone(idx)` | Срабатывает однократно в тик выхода игрока из зоны с индексом `idx`. |

> ⚠️ **Индексация зон:**  
> Зоны нумеруются с `0` в порядке возрастания радиуса (Зона 0 — самое ядро, Зона 1 — внешняя и т.д.).

---

## 🔀 Логические операторы

Поддерживаются скобки для группировки `(...)` и стандартный приоритет операторов (`NOT` > `AND` > `OR`):

| Операция | Текстовый оператор | Символьный оператор |
|---|---|---|
| **Логическое И** | `and` | `&&` |
| **Логическое ИЛИ** | `or` | `||` |
| **Логическое НЕ** | `not` | `!` |

### Пример сложного выражения:
```antlr
state active {
    when (player.entered_zone(0) || timer(100)) && !chance(0.2) -> cooldown;
}
```

## 💡 Полный пример автомата ("Жарка")

```antlr
initial state idle;

recipe cook_pork --> "recipes/cook_pork.json";
recipe make_glass --> "recipes/make_glass.json";

state idle {
    when player.entered_zone(0) -> warmup;
}

state warmup {
    when timer(20) -> burst;
}

state burst {
    recipe {
        cook_pork;
        make_glass;
    }

    when timer(60) -> cooldown;
}

state cooldown {
    when timer(100) -> idle;
}
```
