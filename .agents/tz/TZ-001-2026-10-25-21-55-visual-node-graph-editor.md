## 1. 🎯 Цель и контекст

### Проблема:
В настоящее время настройка аномалий выполняется либо через громоздкие текстовые файлы DSL (`.anom`), либо через примитивные текстовые поля мультитула. Нет наглядного представления конечного автомата (FSM) состояний аномалии, условий переходов и зон действия.

### Решение:
Создать полноценную внутриигровую визуальную среду редактирования на графах (Node Graph Editor) в стиле Unreal Blueprints / Blender Shader Canvas, поддерживающую два режима:
1. **Live World Inspector (Редактор инстанса в мире):** Подключение к конкретной аномалии по UUID, мониторинг стейта в реальном времени, настройка зон, накопление правок и транзакционное сохранение на сервер.
2. **Template Studio (Редактор шаблонов датапаков):** Создание и редактирование шаблонов аномалий с сохранением в файл `.anom` на диск и сопутствующий файл разметки графа `.editor.json`.

## 2. 🏗 Архитектурные требования

### 2.1. Canvas & Рендеринг графа (Client GUI)
- **Координатная сетка Canvas:** Поддержка панорамирования (`panX`, `panY` мышью с зажатым СКМ / пробелом) и масштабирования (`zoom` колесиком мыши 0.3x–2.0x).
- **Матричные трансформации:** Использование `PoseStack` (`translate` + `scale`) для эффективного рендеринга без пересчета мировых экранных координат элементов на каждом кадре.
- **Отрисовка связей:** Кривые Безье 3-го порядка (Cubic Bezier) с портами выхода справа и портами входа слева.
- **Сетка фона (Grid):** Плавная процедурная координатная сетка на темном бэкграунде студии.

### 2.2. Архитектура Ноды («Карточка стейта»)
- Нода представляет собой состояние конечного автомата (`State`).
- Внутри карточки ноды:
  - Имя стейта + метка начального состояния `[START]`.
  - Списки действий: `On Enter`, `Tick`, `On Exit` с компактными иконками и значениями.
  - Порты переходов `when` (по условию: таймер, вероятность, игрок в зоне).
- Клики и перетаскивание нод (AABB drag-and-drop).

### 2.3. Панель свойств (Side Inspector)
- Выдвижная панель справа:
  - При выборе **Стейта**: детальное редактирование триггеров и экшенов.
  - При выборе **Зоны**: форма (Sphere, Box, Cylinder), радиус, эффекты, тяга, урон.
  - При выборе **Связи (Transition)**: конструктор условий (`Timer`, `Chance`, `PlayerInZone`, `PlayerZoneEvent`).

### 2.4. Хранение разметки графа
- Файл логики: `data/<namespace>/anomalies/<name>/<name>.anom` (чистый человекочитаемый DSL, не засоряется координатами GUI).
- Файл разметки графа: `<name>.editor.json` рядом со скриптом:
  ```json
  {
    "canvas": { "panX": 200.0, "panY": 150.0, "zoom": 1.0 },
    "nodes": {
      "idle": { "x": 100, "y": 120 },
      "charging": { "x": 450, "y": 120 },
      "blast": { "x": 800, "y": 120 }
    }
  }
  ```
- **Fallback (Авто-лейаут):** При отсутствии `.editor.json` ноды автоматически выстраиваются слева направо по алгоритму топологической сортировки.

### 2.5. Сеть и Dirty Tracking (Подсветка изменений)
- **Local Draft Pattern:** Все изменения копятся в локальном буфере (`DraftState`), не отправляя микро-пакеты на сервер при каждом движении мыши.
- **Visual Git Diff:**
  - ⚪ **Серый:** Без изменений (исходное состояние из файла/мира).
  - 🔵 **Синий:** Измененные параметры / ноды.
  - 🟢 **Зеленый:** Вновь добавленные стейты / связи.
  - 🔴 **Красный:** Помеченные на удаление элементы.
- **Индикатор несохраненных данных:** Бейдж `● Unsaved Changes` и кнопка `[Сохранить]`.
- **Коммит:**
  - В режиме мира: отправка единого пакета `PacketApplyAnomalyOverrides` на сервер (применение к `LightEntityInstance` и сохранение чанка).
  - В режиме шаблона: локальная запись на диск (`.anom` + `.editor.json`).

## 5. ✅ Критерии приёмки (Definition of Done)
1. Игрок может открыть граф стейтов аномалии через мультитул.
2. Ноды свободно перетаскиваются мышью, зум и панорамирование холста работают плавно (60 FPS).
3. Изменения параметров подсвечиваются синим цветом, пока не нажата кнопка «Сохранить».
4. При сохранении в режиме мира изменения мгновенно применяются к аномалии без необходимости перезахода.
5. При сохранении шаблона генерируются чистый `.anom` файл и сопутствующий `.editor.json` с координатами нод.
